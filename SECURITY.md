# Security policy

HealthOS handles account and personal nutrition data. Please do not publish sensitive information in GitHub issues, discussions or pull requests.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by emailing:

**rudrakshjhalani@gmail.com**

Include a concise description, affected component or endpoint, impact, and reproduction steps where safe. Do not include real user health records, passwords, session cookies, database connection strings, backup files or other secrets.

Please allow reasonable time for acknowledgement and investigation before publicly disclosing a suspected vulnerability. This repository is a proprietary portfolio project; security reports do not imply permission to copy, modify or redistribute its source code.

## Scope and limitations

This is a best-effort reporting channel, not a guaranteed bug-bounty programme or service-level agreement. Do not test against production accounts, data or infrastructure without explicit authorisation.
